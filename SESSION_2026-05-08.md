# Сессия 2026-05-08 — YRM100 UHF RFID компонент ESPHome

## Цель
Разработка и отладка ESPHome-компонента для UHF RFID ридера YRM1002 на ESP32-S3 (плата с Ethernet W5500, Respeaker XVF3800, voice assistant, LED ring).

## Что делали

### 1. Выяснили что прошивка не обновлялась
- Предыдущие изменения файлов в Windows (`C:\Project_OpenCode\YRM1002\`) не попали в бинарник — компиляция шла из WSL (`~/yrm100_project/`), где лежали старые файлы.
- Выяснили что ESP32 грузился с OTA-раздела, а не с factory — поэтому даже прошивка factory.bin не давала эффекта.
- **Решение**: `erase_flash` перед `write_flash` — стирает OTA-данные, устройство грузится с factory.

### 2. Синхронизация Windows → WSL
- Копировали файлы из `/mnt/c/Project_OpenCode/YRM1002/` в `~/yrm100_project/` перед каждой компиляцией:
  - `components/yrm100/yrm100.cpp`
  - `components/yrm100/yrm100.h`
  - `components/yrm100/__init__.py`
  - `esp32-eth.yaml`

### 3. Добавили настраиваемые параметры в YAML
| Параметр | По умолчанию | Описание |
|---|---|---|
| `scan_duration` | 500ms | Длительность одного цикла сканирования |
| `update_interval` | 1s | Период запуска новых циклов опроса |
| `repeat_count` | 10 (→5) | Кол-во попыток инвентаризации за один цикл |

Раньше `repeat_count` был захардкожен как `0x0A` (10) в C++ коде. Теперь задаётся из YAML.

### 4. Добавили бинарный сенсор `tag_present`
- **ON** — хотя бы одна RFID-метка в зоне действия ридера
- **OFF** — ни одной метки не обнаружено
- Переход ON→OFF означает «метка пропала из зоны»

### 5. Почистили код
- Убраны мёртвые объявления `strip_echo_()` и `read_and_discard_echo_()` из заголовка
- Убрана переменная `last_tx_` (не использовалась)

## Конфигурация YRM100 в YAML (итог)

```yaml
yrm100:
  - id: my_rfid
    uart_id: rfid_uart
    scan_duration: 500ms
    update_interval: 1s
    repeat_count: 5
    tag_present:
      name: "RFID Tag Present"
    on_tag:
      then:
        - homeassistant.tag_scanned: !lambda 'return x;'
    on_tag_removed:
      then:
        - lambda: |-
            ESP_LOGI("yrm100", "Tag removed: %s", x.c_str());
```

## Известные метки
- `E28068940000401A48B8507E` (Impinj Monza)
- `000000000000000000001031`

## Железо
- UART: GPIO3 (TX) → GPIO6 (RX), 115200 baud, через двусторонний конвертер уровней 3.3V ↔ 5V
- RFID power: 5V от ESP32-S3 платы
- Протокол YRM100: `BB [type] [cmd] [len 2B] [data] [checksum] 7E`

## Процесс прошивки
```powershell
# Синхронизация файлов
wsl cp /mnt/c/Project_OpenCode/YRM1002/components/yrm100/yrm100.cpp ~/yrm100_project/components/yrm100/
wsl cp /mnt/c/Project_OpenCode/YRM1002/components/yrm100/yrm100.h ~/yrm100_project/components/yrm100/

source ~/esphome-env/bin/activate && cd ~/yrm100_project && esphome compile esp32-eth.yaml

# Копирование бинарника в Windows
wsl cp ~/yrm100_project/.esphome/build/esp32-eth/.pioenvs/esp32-eth/firmware.factory.bin /mnt/c/Project_OpenCode/YRM1002/

# Прошивка (Windows PowerShell) — ОБЯЗАТЕЛЬНО erase_flash перед write_flash!
C:\Users\HOME\AppData\Local\Programs\Python\Python310\python.exe -m esptool --chip esp32s3 --port COM147 --baud 460800 erase_flash
C:\Users\HOME\AppData\Local\Programs\Python\Python310\python.exe -m esptool --chip esp32s3 --port COM147 --baud 460800 write_flash 0x0 C:\Project_OpenCode\YRM1002\firmware.factory.bin
```
