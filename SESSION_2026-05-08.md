# Сессия 2026-05-08 — YRM1002 UHF RFID компонент ESPHome

## Цель
Разработка и отладка ESPHome-компонента для UHF RFID ридера YRM1002 на ESP32-S3 (плата с Ethernet W5500, Respeaker XVF3800, voice assistant, LED ring).

## Что делали

### 1. Выяснили что прошивка не обновлялась
- Предыдущие изменения файлов в Windows (`C:\Project_OpenCode\YRM1002\`) не попали в бинарник — компиляция шла из WSL (`~/yrm100_project/`), где лежали старые файлы.
- Выяснили что ESP32 грузился с OTA-раздела, а не с factory — поэтому даже прошивка factory.bin не давала эффекта.
- **Решение**: `erase_flash` перед `write_flash` — стирает OTA-данные, устройство грузится с factory.

### 2. Синхронизация Windows → WSL
- Копировали файлы из `/mnt/c/Project_OpenCode/YRM1002/` в `~/yrm100_project/` перед каждой компиляцией

### 3. Добавили настраиваемые параметры в YAML
| Параметр | По умолчанию | Описание |
|---|---|---|
| `scan_duration` | 500ms | Длительность одного цикла сканирования |
| `update_interval` | 1s | Период запуска новых циклов опроса |
| `repeat_count` | 10 (→5) | Кол-во попыток инвентаризации за один цикл |
| `power` | 26 dBm | Мощность RF-выхода (0–26 dBm, максимум 26 = ~400 мВт) |

`repeat_count` и `power` раньше были захардкожены в C++ коде. Теперь задаются из YAML.

### 4. Добавили бинарный сенсор `tag_present`
- **ON** — хотя бы одна RFID-метка в зоне действия ридера
- **OFF** — ни одной метки не обнаружено
- Переход ON→OFF означает «метка пропала из зоны»

### 5. Добавили управление мощностью RF
- Изучили протокол из репозитория [Loopack-Systems/YMR100](https://github.com/Loopack-Systems/YMR100)
- Команда `0xB6` (Set Power): данные = dBm × 100, 2 байта big-endian
- Команда `0xB7` (Get Power): чтение текущей мощности
- Диапазон: 0–26 dBm (26 = максимум, ~400 мВт)
- Мощность отправляется при старте в `setup()`

### 6. Переименовали компонент yrm100 → yrm1002
- Неймспейс: `yrm100` → `yrm1002`
- Классы: `YRM100` → `YRM1002`
- Файлы: `yrm100.h/cpp` → `yrm1002.h/cpp`
- Python: все ссылки обновлены

### 7. Опубликовали компонент на GitHub
- Репозиторий: https://github.com/arturgadelshin/YRM1002
- Ветка `main` — стабильная версия
- Ветка `dev` — текущая разработка
- Подключение через `external_components` с `ref: dev`

### 8. Перешли на OTA-прошивку
- Больше не нужен USB (COM147) для каждой прошивки
- `esphome upload --device 192.168.0.114 esp32-eth.yaml` — прошивка по сети за 8 секунд
- Для первой прошивки после erase_flash нужен USB

### 9. Почистили код
- Убраны мёртвые объявления `strip_echo_()` и `read_and_discard_echo_()` из заголовка
- Убрана переменная `last_tx_` (не использовалась)

## Конфигурация YRM1002 в YAML (итог)

```yaml
external_components:
  - source:
      type: git
      url: https://github.com/arturgadelshin/YRM1002
      ref: dev
    components:
      - yrm1002

yrm1002:
  - id: my_rfid
    uart_id: rfid_uart
    scan_duration: 500ms
    update_interval: 1s
    repeat_count: 5
    power: 26
    tag_present:
      name: "RFID Tag Present"
    on_tag:
      then:
        - homeassistant.tag_scanned: !lambda 'return x;'
    on_tag_removed:
      then:
        - lambda: |-
            ESP_LOGI("yrm1002", "Tag removed: %s", x.c_str());

text_sensor:
  - platform: yrm1002
    yrm1002_id: my_rfid
    name: "Last RFID Tag EPC"
```

## Известные метки
- `E28068940000401A48B8507E` (Impinj Monza)
- `000000000000000000001031`

## Железо
- UART: GPIO3 (TX) → GPIO6 (RX), 115200 baud, через двусторонний конвертер уровней 3.3V ↔ 5V
- RFID power: 5V от ESP32-S3 платы
- Протокол YRM1002: `BB [type] [cmd] [len 2B] [data] [checksum] 7E`
- Команда мощности: `BB 00 B6 00 02 [dBm_hi] [dBm_lo] [checksum] 7E`

## Процесс прошивки

### OTA (основной способ)
```bash
# WSL
source ~/esphome-env/bin/activate && cd ~/yrm100_project
esphome upload --device 192.168.0.114 esp32-eth.yaml
```

### USB (первичная / аварийная)
```powershell
# ОБЯЗАТЕЛЬНО erase_flash перед write_flash!
python -m esptool --chip esp32s3 --port COM147 --baud 460800 erase_flash
python -m esptool --chip esp32s3 --port COM147 --baud 460800 write_flash 0x0 firmware.factory.bin
```
